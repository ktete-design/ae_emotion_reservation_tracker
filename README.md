# Aぇ! group「Emotion」予約管理

GitHub Pagesで公開できる、1ファイル構成の予約管理サイトです。

## 機能
- 初回A/B/C・通常盤①〜③の予約を登録
- 予約先と枚数を記録
- 予約一覧・合計枚数・形態別集計
- 楽曲・映像・初回盤特典の不足チェック
- 自担を選択して交換候補を表示
- 交換済みチェック、交換相手メモ
- ブラウザのlocalStorageに端末保存

## GitHub Pages
1. GitHubで新しいPublic Repositoryを作る
2. `index.html` をアップロード
3. Settings → Pages → Deploy from a branch → `main` / `/root`
4. 数分後に公開URLが発行されます。

## 注意
予約データはサーバーに保存せず、利用しているブラウザ端末内だけに保存します。
